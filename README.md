# 🏃 Run — 3D Runner

A fast-paced 3D endless runner game built with Unity.

## 🎮 About

**Run** is a 3D runner game where the player navigates through an endless course, dodging obstacles and surviving as long as possible. The game features custom shaders and visual effects built with ShaderLab and HLSL for a polished look.

## 🛠️ Built With

- **Unity** — Game engine
- **C#** — Game logic and mechanics
- **ShaderLab / HLSL** — Custom shaders and visual effects

## 🚀 Getting Started

### Prerequisites

- Unity Editor (recommended: the version this project was created with)

### Running the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/BuggyMan21/Run.git
   ```
2. Open **Unity Hub** and click **Open Project**.
3. Navigate to the cloned folder and open it.
4. Once the project loads, open the main scene from the `Assets` folder.
5. Press **Play** in the Unity Editor to run the game.
